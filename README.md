# TIDETALE — LAST TIDE

Undertale AU のサンズ戦（非公式ファンゲーム）。`index.html` をブラウザで開くだけで遊べます（単一ファイル／画像・音源すべて自作・生成）。

## 操作
- 矢印 / WASD：移動　Z / Enter：決定　X / Esc：戻る　Shift：ゆっくり移動（当たり判定の目安が出ます）　M：ミュート
- スマホ：画面下の十字キーと「決定」「戻る(遅)」ボタン（横画面推奨）

## 内容
- ターン制（たたかう／こうどう／アイテム／みのがす）＋ 6 つの弾幕ターン
- オリジナル砲台「ルナ」（ガスターブラスター風）、枠が四角→円→ひし形へ変形・移動
- 青いソウル（重力）ターン、月食ターン（青・橙の弾）、最終ターン「LAST TIDE」
- エンディング 3 種（「話す」を3回以上選んで見逃す／見逃す／倒す）

## メモ
- 日本語フォントは Google Fonts の DotGothic16（オフライン時は代替フォント）
- 音楽・効果音は Web Audio API で生成
