# TIDETALE — LAST TIDE

Undertale AU のサンズ戦（非公式ファンゲーム）。`index.html` をブラウザで開くだけで遊べます（単一ファイル）。

絵・弾・枠・エフェクトはすべてドット絵（480×270 のフレームバッファに 1 ドットずつ描画し、整数倍で拡大）。画像素材なし、音楽・効果音は Web Audio で生成。

## 操作
- 矢印 / WASD：移動　Z / Enter：決定　X / Esc：戻る　Shift：ゆっくり移動　M：ミュート
- 灯蛾ターンのみ Z でランタンを置く
- スマホ：画面下の十字キーと「決定」「戻る(遅)」ボタン（横画面推奨）

## 攻撃（各ターンが、この AU 固有の仕組み）
1. 鏡面：水面に映った「自分」にも当たり判定。上の弾は本体、下の弾は映った像に当たる
2. 屈折：ルナの光が水面で曲がる／全反射する。予告線は曲がった先まで出る
3. 波乗り：進む波の上を走る青いソウル。波が持ち上がる瞬間に高く跳ぶ
4. 灯蛾：蛾は一番近い光に集まる。Z で置くランタンで誘導する
5. 月食：黒い月が引力で全てを引き寄せ、弾が軌道を描く
6. LAST TIDE：水位上昇（水中は遅く浮く）→ 月 → 蛾 → 鏡面の高速版
